# DeepSeek V4 Flash 0731 + MiniMax H3 City Routing

This integration adds two different workers to the Intelligence Grid. They must not be collapsed into one generic model lane.

## Role separation

| Worker | City role | Correct use |
| --- | --- | --- |
| DeepSeek V4 Flash 0731 through Nous Portal | fast text, code, terminal and tool-planning worker | high-volume bounded tasks that can be validated cheaply |
| MiniMax H3 | audiovisual media execution worker | short-form multimodal video generation and editing with governed references |

HERMES remains the router. Mission Control remains the human control plane. AEGIS remains the assurance layer. Neither model receives sovereign authority.

## DeepSeek promotional routing rule

The reported Nous Portal and Novita Labs promotion is treated as a temporary economics signal.

```text
price signal observed
  -> verify live model identifier and price in Portal
  -> run district eval pack
  -> compare accepted-output cost
  -> enable temporary preferred route
  -> record every call
  -> automatically fall back when price, quality or availability changes
```

Do not encode the promotion as a permanent city dependency. The reported 90% discount, seven-day duration, Terminal-Bench 2.1 result and 1000x comparison must remain attributed claims until independently reproduced or backed by a durable provider record.

### Allowed during promotion

- repository inventory and triage
- code and test drafts
- low-risk terminal tasks inside a sandbox
- content variants
- prompt compilation
- structured extraction and classification
- game scripting drafts
- fashion catalog enrichment
- creator and ASBE workflow scaffolding
- synthetic eval generation

### Escalate before adoption

- production mutations
- deployment
- security decisions
- wallet or payment actions
- secrets and credentials
- destructive file operations
- regulated decisions
- final approval of public claims

## MiniMax H3 routing rule

H3 is a queued media provider behind the MCP Capability Bus.

```text
creative mandate
  -> HERMES shot plan
  -> canonical asset manifest
  -> AEGIS rights and identity gate
  -> H3 submit
  -> durable task queue
  -> status polling with backoff
  -> output retrieval and hashing
  -> ASBE assembly and QC
  -> Mission Control approval
  -> PBX / GTM distribution
```

H3 is not the city brain. It may generate or edit media, but it may not decide what is published, which identity is cloned, whether rights are cleared or whether a campaign is truthful.

## Cost policy

Optimize for cost per accepted and validated artifact, not raw token or generation price.

```text
accepted_cost = total_provider_spend
              + validation_cost
              + correction_cost
              + rejected_generation_cost
              divided by accepted_outputs
```

A cheap model that creates repair work is not cheap. A powerful model with no authority boundary is not safe.

## Receipt requirements

### DeepSeek receipt

- requested and resolved model ID
- provider and upstream provider
- price snapshot and timestamp
- promotion status observed at execution
- task and risk classes
- token counts and latency
- sandbox and tool permissions
- test or validation result
- human approval when required

### H3 receipt

- resolved model ID
- mandate ID
- prompt and asset-manifest hashes
- reference files and their declared roles
- rights and identity-consent status
- duration and resolution
- provider task ID
- output hash
- QC and continuity result
- human approval
- destination channels

## Fallback behavior

- If the DeepSeek promotion expires, price rises, quality drops or the model alias changes, route through the standard Fast Worker or Builder council based on task class.
- If H3 is unavailable or fails rights, quality or continuity checks, route the shot to another approved media provider or return it for prompt and asset repair.
- Never silently substitute a model for identity-sensitive media or elevated execution. Record the substitution in the receipt.

## Canon

**DeepSeek V4 Flash is temporary high-volume leverage. MiniMax H3 is bounded media production. HERMES routes. AEGIS checks. Mission Control decides. The receipt remembers.**
